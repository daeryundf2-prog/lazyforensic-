# frontend-ui-ux — Meng To UI 카탈로그

웹 UI 참고용이다. 포렌식 수집/감정 도구가 아니며, DesignCode 자산의 재배포 권한을 보증하지 않는다.

이 스킬은 `mengto-skills/`의 레이아웃 규칙을 읽어 HTML 뷰어를 만들 때 쓴다.

---

## 🎨 주요 지원 디자인 스킬 카테고리 (127개 내장)

### 1. 포렌식 데이터 & 타임라인 인터페이스 (`mengto-skills/web-design/`)
* **`scroll-progress-timeline`**: 스크롤 연동 시계열 사건 흐름도 및 진행 바 애니메이션
* **`technical-wireframe-info-layout`**: 고밀도 포렌식 아티팩트/로그 테크니컬 와이어프레임 뷰
* **`split-layout-technical`**: 좌측 타임라인 + 우측 증거 상세 정보 분할 레이아웃
* **`editorial-tech`**: 비대칭 그리드와 테크니컬 타이포그래피 기반 프리미엄 보고서 뷰어
* **`framed-grid-layout`**: 고급스러운 보더 라인과 카드 컨테이너 그리드

### 2. 최첨단 다크 모드 & 비주얼 이펙트
* **`glass-dark-ui` / `dark-glass-clean-layout`**: 정교한 배경 블러(Backdrop blur)와 반투명 다크 글래스모피즘
* **`beautiful-shadows`**: 레이어별 자연스러운 멀티 레이어 박스 섀도우
* **`css-border-gradient` / `liquid-metal-border`**: 미세한 그라디언트 테두리 하이라이트
* **`atmosphere-background` / `mesh-gradient-dark-blue-clean`**: 깊이감 있는 앰비언트 배경 조명

### 3. 인터랙션 및 모션 시스템
* **`cinematic-gsap-lenis-motion-system` / `gsap-scrolltrigger-storytelling`**: 부드러운 스크롤 모션 및 스토리텔링 인터랙션
* **`threejs` / `webgl-3d-object` / `cobejs` / `globe-gl`**: 3D 인터랙티브 글로브 및 침해 사고 유출 경로 3D 시각화

# forensic-timeline: 디지털 포렌식 전수 타임라인 생성 및 시각화

이 스킬은 PC 아티팩트, 파일 시스템 타임스탬프(MACB), 모바일 메신저 대화, 웹 히스토리, DLP 로그 등 다중 소스의 시계열 데이터를 결합하여 **특정 일자·시간대의 분 단위 행위 전수 타임라인(Timeline)**을 작성하고 시각화합니다.

## 🎯 주요 실행 시나리오 (Triggers)
- "PC 사용기록 타임라인 만들어줘", "타임라인 보고서 작성해줘", "특정 시간대 행위 분석해줘"
- "1월 16일 2시부터 4시까지 행위 타임라인 정리", "공백행위 타임라인 분석"
- "PDF/HTML 타임라인으로 변환해줘", "전수 타임라인 표 작성"

---

## 🛠️ 작업 표준 절차 (Standard Operating Procedure)

### 1단계: 타임스탬프 원천 데이터 수집 및 정규화
- 분석 대상 파일(엑셀, CSV, TXT, JSON, DB, PDF)에서 다음 4가지 핵심 필드를 추출:
  1. **타임스탬프 (KST 기준)**: `YYYY-MM-DD HH:MM:SS` 표준 포맷으로 정규화 (UTC인 경우 +9시간 보정 명시)
  2. **행위 주체 / 소스**: 프로세스명, 파일 경로, 사용자 계정, 대화 참여자
  3. **행위 유형 (Activity Type)**: `[파일 생성]`, `[파일 수정]`, `[파일 실행]`, `[웹 검색/방문]`, `[메신저 대화]`, `[USB 연결]`, `[DLP 차단/전송]` 등 카테고리화
  4. **상세 내용 및 아티팩트 근거**: 파일명, 대상 경로, 검색어, 대화 내용, SHA-256 해시, 레지스트리 키 등

### 2단계: 핵심 분석 구간(Focus Window) 및 공백 행위 격리
- 의뢰인 또는 사건의 핵심 쟁점 시간대(예: 퇴사 직전 2시간, 특정 파일이 수정된 시점 전후 30분)를 집중 줌인(Zoom-in).
- **공백 시간(Gap Analysis)**: 시스템 전원 On 상태임에도 사용자 입력/파일 활동이 없는 구간을 명시하고, 백그라운드 프로세스나 의도적 증거인멸 가능성 여부를 검토.

### 3단계: 인터랙티브 HTML 및 인쇄용 PDF 출력
- 내장 스크립트 `scripts/generate_timeline.py`를 활용하거나 모던 반응형 HTML 템플릿으로 출력.
- **필수 포함 요소**:
  - **사건 메타데이터**: 사건번호, 대상 기기명/드라이브명, 분석관, 분석 일시
  - **시간대별 요약 통계 카드**: 총 이벤트 수, 파일 수정 건수, 메신저 송수신 건수, 검색 기록 건수
  - **필터링 기능**: 행위 유형별(파일/웹/메신저/시스템) 필터 버튼 및 시간 검색창
  - **색상 기반 가시화**:
    - 🔴 중요/이상 징후/유출 의심: `#DC2626`
    - 🔵 일반 사용자 행위: `#2563EB`
    - 🟢 시스템 자동 백그라운드 행위: `#16A34A`
    - 🟠 메타데이터 변경/이동: `#D97706`

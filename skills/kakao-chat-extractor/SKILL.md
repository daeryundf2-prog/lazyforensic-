# kakao-chat-extractor: 모바일/카카오톡 대화방 파싱 및 증거 추출

이 스킬은 스마트폰(Android/iOS) 라이브 수집물 및 카카오톡 내보내기 텍스트/CSV/SQLite 데이터에서 **특정 인물 간의 대화, 특정 기간의 대화, 핵심 키워드(횡령, 기밀유출, 협박, 금전 등)가 포함된 메시지**를 고속으로 추출하여 증거 목록표로 정제합니다.

## 🎯 주요 실행 시나리오 (Triggers)
- "카카오톡 대화방 폴더별로 검토해서 무슨 내용이 있는지 리스트화해줘"
- "정시원, 최백랑 대화방에서 특정 일자 대화 추출해줘"
- "아이폰/안드로이드 카카오톡 대화 내역 분석", "채팅방 증거 목록표 작성"

---

## 🛠️ 카카오톡 파싱 표준 포맷 지원
1. **모바일 텍스트 내보내기 포맷**:
   - `--------------- 2024년 1월 16일 화요일 ---------------`
   - `[홍길동] [오후 2:15] 안녕하세요.`
2. **PC 버전 내보내기 포맷**:
   - `[2024-01-16 14:15:22] 홍길동: 안녕하세요.`
3. **CSV / SQLite DB (`chat_logs`) 테이블**:
   - `_id`, `chat_id`, `user_id`, `message`, `created_at`

---

## 📊 추출 산출물 (Outputs)
- **인물별/대화방별 대화 통계**: 총 대화 수, 주고받은 사진/동영상/파일 수, 최초/최종 대화 일시
- **핵심 쟁점 대화 타임라인 표**: 시간순 정렬된 발신자-수신자 대화 내역 (증거 번호 부여)
- **의심 키워드 하이라이팅**: 사건 관련 키워드 강조 표시
